TikTok Affiliate Uploader

A personal, self-hosted content-scheduling dashboard used by the account owner to publish their own short-form videos to their own TikTok account, for affiliate marketing purposes.

What this app does

  • Lets the account owner connect their own TikTok account via TikTok Login Kit (OAuth 2.0).
  • Lets the account owner select a video file stored locally and publish it directly to their own TikTok profile using the Content Posting API (Direct Post).
  • Lets the account owner set a caption, privacy level, and content settings (duet/stitch/comment, AI-generated content label) before publishing.

Data usage

This app only accesses the TikTok account the owner explicitly connects. Access tokens are stored locally on the owner's own machine and are never shared with any third party. See our Privacy Policy and Terms of Service for details.
